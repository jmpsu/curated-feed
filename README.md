# Joey's Curated Stream

A user-specific, continuously tuned media stream that presents selected articles, videos, images, and signals as an autonomous slideshow.

## Current release

The first coherent release includes timed carousel playback, manual navigation, a visual story timeline, tag search and drag/drop focus controls, tag weights and exclusions, likes and saves, a live-headline rail, responsive layouts, and browser persistence.

Read [REQUIREMENTS.md](REQUIREMENTS.md) for the complete requirements, evidence, architecture, comparison record, and delivery boundary.

## Local development

\`\`\`bash
npm ci
npm run build
\`\`\`

The hosted release is managed through ChatGPT Sites. Production data adapters and account authorization are intentionally separated from the interaction prototype.
